# @james/api

Types for [James](../../README.md) plugins. Install it as a dev dependency for type checking and
editor support:

```sh
npm install --save-dev <path to James>/packages/api
```

The plugin guide is [docs/plugins/README.md](../../docs/plugins/README.md); the API reference is
the [plugin API site](https://hudint.github.io/James/), generated from `index.d.ts` (see
[`apidocs/`](../../apidocs)). MIT licensed, so plugins may use any license.
